# Prompt 13 — Revisión de PR

Revisá el diff contra `main` sin modificar inicialmente.

Comprobar:

- `AGENTS.md`;
- alcance;
- riesgos;
- lifecycle;
- concurrencia;
- tiempo real;
- seguridad;
- privacidad;
- accesibilidad;
- tests;
- documentación;
- archivos grandes;
- dependencias;
- claims.

Clasificar: bloqueante, importante, menor y observación.

Después proponer parche mínimo solo para bloqueantes e importantes. Sin refactors ajenos.
