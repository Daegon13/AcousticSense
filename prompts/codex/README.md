# Prompts para Codex

## Uso

1. Crear la rama sugerida.
2. Abrir Codex en la raíz.
3. Pegar un solo prompt.
4. Revisar el plan.
5. Ejecutar pruebas localmente.
6. Probar en teléfono cuando corresponda.
7. Revisar diff y crear PR.
8. Actualizar estado.
9. Recién entonces usar el siguiente.
