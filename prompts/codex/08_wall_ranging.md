# Prompt 08 — Pared

Rama: `feat/wall-ranging`

Implementá estimación experimental para una pared grande, plana y rígida:

- señal conocida;
- correlación/filtro adaptado;
- rechazo directo;
- compensación;
- candidatos;
- distancia;
- confianza;
- “sin medición confiable”;
- historial;
- exportación;
- análisis offline reproducible.

La UI debe pedir distancia real durante el experimento.

No incluir vibración de movilidad, clasificación, navegación o uso caminando.

Tests: ecos, ruido, múltiples ecos, sin eco y offset.

Actualizar métricas, estado y experimento.
