# Glosario

**Chirp:** señal cuya frecuencia cambia con el tiempo.

**DSP:** procesamiento digital de señales.

**Full-duplex:** reproducción y captura simultáneas.

**Eco:** reflexión recibida tras la señal directa.

**Correlación:** localización de una señal conocida.

**Filtro adaptado:** detector para una forma conocida.

**Time of flight:** tiempo de viaje.

**Offset:** retraso del sistema.

**Xrun:** underrun u overrun.

**Sample rate:** muestras por segundo.

**JNI:** frontera Java/Kotlin-C++.

**NDK:** herramientas para código nativo.

**Oboe:** biblioteca C++ de audio Android.

**Ground truth:** valor real de referencia.

**MAE:** error absoluto medio.

**P95:** percentil 95.

**Gate:** condición para avanzar.
