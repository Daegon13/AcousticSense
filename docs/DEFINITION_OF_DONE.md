# Definition of Done

Un PR termina cuando:

- cumple un objetivo;
- compila;
- tests y lint pasan;
- no introduce warnings relevantes sin explicar;
- no modifica archivos ajenos;
- documentación está actualizada;
- errores están cubiertos;
- no contiene secretos ni datos grandes;
- el diff fue revisado;
- límites están declarados;
- se indicó qué no fue probado físicamente.

Para audio: cierre de streams, lifecycle, errores, sin I/O en callback y xruns.

Para DSP: caso sintético, tolerancia, ruido, múltiples ecos y regresión.

Para accesibilidad: TalkBack, foco, etiquetas, controles y no depender de color.
