# Límites del MVP

## Incluido

- Android.
- Uno a tres modelos validados.
- Procesamiento local.
- Calibración.
- Sensor frontal.
- Distancia aproximada o zonas.
- Confianza.
- Vibración.
- TalkBack.
- Inicio y parada.
- Diagnóstico.
- Exportación.

## Excluido

- iOS;
- wearables;
- Bluetooth;
- cámara;
- LiDAR;
- IA;
- clasificación;
- mapas;
- SLAM;
- rutas;
- navegación exterior;
- 360°;
- bolsillo;
- escalones descendentes;
- pozos;
- cables;
- tráfico;
- backend;
- cuentas;
- publicación pública;
- afirmaciones de seguridad.

## Contexto permitido

Demostración, laboratorio, pruebas controladas, visión disponible, supervisión y orientación definida.

La salida debe ser una distancia, una zona o “sin medición confiable”; nunca una respuesta inventada.
