# Flujo con Codex

## ChatGPT

Arquitectura, planificación, prompts, revisión conceptual, logs y decisiones.

## Codex

Inspección, edición, tests, compilación, diff y PR.

## Equipo humano

Android Studio, teléfono, permisos, pruebas físicas y evaluación de seguridad.

Codex no puede validar físicamente ecos, latencia ni distancia.

## Uso

1. Crear rama.
2. Pegar un prompt.
3. Revisar plan.
4. Ejecutar pruebas.
5. Probar en teléfono.
6. Revisar diff.
7. Crear PR.
8. Actualizar estado.
9. Avanzar.

No ejecutar dos prompts de implementación a la vez.
